## Who it’s for

Anyone curious about recent math landmarks (Astra’s ten, Fields highlights, Clay Millennium open set, Goldbach, twin primes, Collatz, and more) without wading through papers first.

## Quick start

**Requires Node.js.** Sticky URL: **http://127.0.0.1:5204**

| | |
|--|--|
| macOS | Double-click **`run.command`** |
| Windows | Double-click **`run.bat`** |
| Terminal | `npm install && npm run dev` |

## Features

- Breakthroughs + landmarks ranked by importance
- Separate **Open problems** catalog
- Plain-language summaries with **Go deeper**
- Interactive demos for intuition (not formal verification)

## Limitations

- Mix of human research and AI-assisted claims (some with Lean certificates)
- Does **not** machine-check proofs; peer review may still be pending
- Demos are intuition tools, not formal verification

## Development

`npm run dev` on sticky port **5204** (`strictPort`).
